# 도망쳐, 꼬물이!

몰려오는 벌레를 피해 최대한 오래 살아남는 2D 아케이드 생존 게임입니다.
2010년 안드로이드 게임 '레이디 버그'(donxu)의 규칙을 참고했고, 그림·캐릭터·이름은 모두 새로 만들었습니다.

## 게임 규칙

- 일정 간격마다 **위쪽에서 벌레 떼가 한꺼번에** 나옵니다. 각 벌레는 나오는 순간 **내가 있던 자리**를 향해 곧장 날아갑니다.
- 마지막 순간 옆으로 빠지면, 벌레들은 내가 있던 자리로 몰려가 엉킵니다.
- **별씨앗**은 위에서 나타나 벽에 튕기며 떠다닙니다. 벽에 5번 부딪히면 사라지니 쫓아가서 먹으세요.
- 별씨앗을 먹으면 그 자리에 **별꽃**이 3초 동안 피어서, 닿는 벌레를 모두 없앱니다. 별꽃 옆에 서 있으면 다음 벌레 떼가 나를 노리다 꽃으로 뛰어듭니다.
- 1초 버틸 때마다 생존 점수, 벌레를 없앨 때마다 처치 점수를 얻습니다. 점수가 오를수록 단계가 올라가 벌레 떼가 커지고 자주 나오며, 점수도 커집니다.

## 실행 방법

- **가장 쉬운 방법:** `index.html` 파일을 더블클릭해서 브라우저(Chrome, Edge, Safari 등)로 엽니다. 서버나 설치가 필요 없습니다.
- **스마트폰에서 해 보기:** 같은 와이파이에 연결된 PC에서 아래 명령으로 간단한 서버를 켠 뒤, 폰 브라우저로 `http://PC의IP주소:8000` 에 접속합니다.
  ```
  python3 -m http.server 8000
  ```

## 조작

| 기기 | 방법 |
| --- | --- |
| PC | WASD 또는 방향키로 이동, Space / Enter 로 시작·재시작 |
| 스마트폰 | 화면 아무 곳이나 드래그. 손가락이 움직인 만큼 캐릭터가 움직여서 손가락이 캐릭터를 가리지 않습니다 |

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 게임 화면의 뼈대 (상단 정보, 시작/게임 오버 화면) |
| `css/style.css` | 화면 꾸미기 |
| `js/config.js` | **난이도·속도 같은 숫자 모음** (여기만 고쳐도 게임 느낌이 바뀝니다) |
| `js/view.js` | 화면 크기 맞추기, 배경 그리기 |
| `js/input.js` | 키보드·터치 입력 |
| `js/player.js` | 주인공 꼬물이 이동과 그리기 |
| `js/enemies.js` | 벌레 등장 규칙, 이동, 포위 공격 |
| `js/item.js` | 반짝별 아이템과 충격파 |
| `js/effects.js` | 파편, 화면 흔들림, 번쩍임 같은 효과 |
| `js/ui.js` | 점수 표시, 시작/게임 오버 화면 |
| `js/game.js` | 게임 진행 (시작 → 플레이 → 게임 오버) |
| `js/main.js` | 모든 것을 준비하고 게임을 돌리기 시작 |
| `js/storage.js` | 최고 기록 저장 |
